Leitura estratégica

O sucesso não está no conteúdo

Está em vencer dois gargalos. Todo o cronograma foi desenhado em torno deles — ignorá-los é onde eventos assim costumam desandar.

Risco 01

A instalação

Público zero-técnico instalando Node, terminal, Git e chaves de API ao vivo é onde 80% dos eventos travam. Se 30 pessoas empacam no setup, perde-se o Dia 1 inteiro e o clima cai. Solução: Fase Zero + regra "ninguém avança travado".

Risco 02

O choque de paradigma

Eles só conhecem o ChatGPT — uma caixinha no navegador. AIOX é CLI + agentes: outro planeta mental. Sem um momento "uau" logo cedo, desistem antes de entender o valor. Solução: caso real funcionando na 1ª hora.

Antes de tudo

Fase Zero — Pré-evento

Uma semana antes. Inegociável. O objetivo é simples: ninguém chega no Dia 1 com a máquina "crua".

1 semana antes · Online
  • Checklist de pré-requisitos enviado — Node 18+, conta GitHub e Claude Code instalado, com vídeo curtinho passo a passo.
  • Sessão de "setup assistido" (opcional, 1h) — online, 2 dias antes, para resgatar quem travou na instalação.
  • Kit de boas-vindas — o que é o AIOX em 1 página + o que cada um vai sair construindo no fim dos 3 dias.

Recomendações do PM

Decisões que sustentam o evento

🧑‍🏫

Proporção de monitores

1 para cada 6–8 alunos nos blocos hands-on. Sem isso, gente zero-técnica empaca e o ritmo da sala morre.

🚦

Ninguém avança travado

Regra de ouro no setup do Dia 1 — o ponto de maior risco do evento inteiro. Checkpoint coletivo antes de seguir.

📦

Entregável visível por dia

Gente de negócio precisa VER resultado, não teoria. Cada dia fecha com algo concreto nas mãos.

🗂️

Trilhas de projeto prontas

4–5 projetos pré-mapeados (landing page, calendário de conteúdo, roteiro de atendimento…) para quem não souber o que escolher.
