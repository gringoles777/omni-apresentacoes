Regra

Obrigatorio em toda pagina HTML da OMNI Brasil.

Toda pagina HTML criada para a OMNI Brasil deve incluir este header como primeiro elemento visivel. O subtitulo muda conforme a pagina (ex: "Changelog", "Backlog", "Design System"), mas a estrutura e os tokens sao fixos. Nenhuma pagina deve usar header alternativo ou omitir este componente.
