AD-MIDAS / GOOGLE ADS

Conectar Google Ads ao Ad-Midas

Passo a passo para gerar as credenciais necessarias

Pegar seu Customer ID

~2 minutos
  1. Abra o Google Ads: ads.google.com
  2. Faca login com sua conta Google
  3. No canto superior direito, voce vai ver um numero no formato:
123-456-7890
  1. Anote esse numero — esse e seu Customer ID

Pegar o Developer Token

~5 minutos
  1. Dentro do Google Ads, clique no icone de ferramentas (chave inglesa) no topo
  2. Em "Configuracao", procure "Centro de API" ou acesse direto: ads.google.com/aw/apicenter
  3. Se nunca usou, vai aparecer um botao para solicitar acesso a API — clique e preencha
  4. Nivel: Basico (suficiente para comecar)
  5. Depois de aprovado, vai aparecer seu Developer Token:
ABcdEfGhIjK123
  1. Anote esse token
Nota: Se o acesso basico nao for aprovado na hora, o Google pode pedir revisao. Nesse caso, avise o Michael.

Criar credenciais OAuth2 no Google Cloud

~10 minutos

Essa e a parte mais longa, mas vai clique por clique:

3.1 — Criar projeto no Google Cloud

  1. Acesse: console.cloud.google.com
  2. Faca login com a MESMA conta Google do Google Ads
  3. No topo, clique no seletor de projeto (ao lado de "Google Cloud")
  4. Clique "Novo Projeto"
    • Nome: OMNI Ads (ou qualquer nome)
    • Clique "Criar"
  5. Selecione o projeto recem-criado

3.2 — Ativar a API do Google Ads

  1. No menu lateral, va em "APIs e Servicos" > "Biblioteca"
  2. Pesquise por "Google Ads API"
  3. Clique no resultado e depois em "Ativar"

3.3 — Configurar tela de consentimento

  1. Va em "APIs e Servicos" > "Tela de consentimento OAuth"
  2. Escolha tipo "Externo" e clique "Criar"
  3. Preencha:
    • Nome do app: OMNI Ads
    • E-mail de suporte: seu e-mail
    • E-mail do desenvolvedor: seu e-mail
  4. Clique "Salvar e Continuar" em todas as telas seguintes (pode pular escopos e usuarios de teste)

3.4 — Criar as credenciais OAuth2

  1. Va em "APIs e Servicos" > "Credenciais"
  2. Clique "+ Criar Credenciais" > "ID do cliente OAuth"
  3. Tipo de aplicativo: "App para computador" (Desktop app)
  4. Nome: OMNI Ads Client
  5. Clique "Criar"
  6. Vai aparecer uma janela com dois valores:
Client ID: 123456789-abc.apps.googleusercontent.com Client Secret: GOCSPX-abcdefg123
  1. Anote os dois valores

Gerar o Refresh Token

~10 minutos
  1. Acesse: developers.google.com/oauthplayground
  2. No canto superior direito, clique no icone de engrenagem (OAuth 2.0 configuration)
  3. Marque "Use your own OAuth credentials"
  4. Cole o Client ID e o Client Secret que voce anotou na Etapa 3
  5. Feche a engrenagem
  6. No painel da esquerda, procure "Google Ads API". Se nao aparecer, digite manualmente no campo "Input your own scopes":
https://www.googleapis.com/auth/adwords
  1. Clique "Authorize APIs"
  2. Vai abrir tela do Google pedindo permissao — faca login e clique "Permitir"
App nao verificado? Se aparecer essa tela, clique em "Avancado" > "Acessar OMNI Ads (nao seguro)". E normal para apps em desenvolvimento.
  1. Voce vai voltar ao Playground. Clique "Exchange authorization code for tokens"
  2. Na resposta, procure o campo "refresh_token":
1//0abc-defg_HIJK...
  1. Anote esse refresh token
