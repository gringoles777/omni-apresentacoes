Comece por aqui

A configuração inicial

Faça uma vez só. Depois é só usar.

1
🐙

Criar sua conta no GitHub

O GitHub é onde seus projetos vão morar com segurança, na nuvem. Pense nele como o seu "Google Drive" para o Mastermind.

→ github.com Clique em "Sign up"
  1. Digite o endereço acima no seu navegador.
  2. Clique no botão Sign up (cadastrar-se).
  3. Informe seu e-mail, crie uma senha e escolha um nome de usuário.
  4. Confirme o e-mail que o GitHub vai te enviar. Pronto!
💡Anote seu nome de usuário e senha em um lugar seguro — você vai usá-los nos próximos passos.
🤍Respira fundo: é um cadastro comum, igual a qualquer site. Se travar em alguma etapa, fale com a Julia.
2
💻

Instalar o GitHub Desktop ⊞ Windows⌘ Mac

É o programa que conecta seu computador ao GitHub, com botões simples — sem precisar digitar comandos.

→ desktop.github.com Download
  1. Acesse o site e clique em Download.
  2. Abra o arquivo baixado e instale (o programa abre sozinho ao terminar).
  3. Faça login com a conta do GitHub que você criou no Passo 1.
😊Não se preocupe, é só clicar em Next! A instalação cuida de tudo sozinha.
3
🟢

Instalar o Node.js ⊞ Windows⌘ Mac

É um motor que o Mastermind usa por baixo dos panos. Você não vai mexer nele — só precisa estar instalado.

→ nodejs.org Botão verde "LTS"
  1. Acesse o site e clique no botão grande que diz LTS (a versão recomendada).
  2. Abra o arquivo baixado.
  3. Na instalação, é só clicar em Next (Avançar) em tudo, até Finish.
✨Não precisa mudar nenhuma opção. Os valores que já vêm marcados são os corretos.
🤍Não se preocupe, é só clicar em Next! Se ficar na dúvida, fale com a Julia.
4
🧩

Instalar o VS Code ⊞ Windows⌘ Mac

O VS Code é o programa onde tudo vai acontecer — é a "mesa de trabalho" do Mastermind. É dentro dele que o seu assistente de IA vai viver.

→ code.visualstudio.com Download for Windows / Mac
  1. Acesse o site acima no seu navegador.
  2. Clique no botão Download for Windows (ou Mac, se for o seu caso).
  3. Abra o arquivo baixado e instale normalmente — Next em tudo.
😊Não se preocupe, é só clicar em Next! Não precisa mexer em nenhuma configuração.
5
🤖

Instalar a extensão Claude Code no VS Code

Este é o seu assistente de inteligência artificial — o coração do Mastermind AIOX. Ele se instala dentro do VS Code, como uma extensão. É bem simples!

  1. Abra o VS Code que você acabou de instalar.
  2. Na barra lateral esquerda, clique no ícone de extensões (o ícone de 4 quadradinhos).
  3. Na caixa de busca, pesquise por Claude Code.
  4. Clique no botão Install (instalar).
  5. Quando ele pedir, faça login com a sua conta Anthropic.
💡O ícone de extensões fica do lado esquerdo da tela. Parece quatro quadradinhos, com um deles se soltando.
🤍Calma, é só pesquisar e clicar em Install. Se não achar o ícone ou travar, fale com a Julia — ela te mostra em 1 minuto.
6
📥

Baixar o seu repositório

Agora vamos trazer a sua pasta de trabalho do Mastermind para o seu computador, usando o GitHub Desktop.

  1. Abra o GitHub Desktop.
  2. No menu superior, clique em File → Clone repository.
  3. Vá na aba URL.
  4. No campo de endereço, digite o seu repositório (troque SEU-NOME pelo seu nome):
digite: gringoles777/mastermind-SEU-NOME
  • Clique em Clone e aguarde o download terminar.
📌Não tem certeza do nome exato do seu repositório? Chame a Julia — ela te passa em segundos.
😊Tranquilo: o GitHub Desktop faz o download sozinho. Se travar em alguma etapa, fale com a Julia.
7
📂

Abrir a pasta no VS Code

Vamos abrir a pasta que você acabou de baixar dentro do VS Code. A partir daqui, é tudo num lugar só.

  1. Abra o VS Code.
  2. No menu superior, clique em File → Open Folder (Arquivo → Abrir Pasta).
  3. Navegue até a pasta que você clonou no GitHub Desktop (no Passo 6).
  4. Selecione a pasta e clique em Abrir.
✨O Claude Code vai aparecer na barra lateral do VS Code — sinal de que está tudo certo!
🤍É só escolher a pasta e abrir, nada além disso. Se não encontrar a pasta, fale com a Julia.
8
🚀

Como usar o Claude Code

Último passo! Agora você vai conversar com os agentes do Mastermind. A partir daqui, a mágica começa. ✨

  1. Clique no ícone do Claude Code na barra lateral do VS Code.
  2. Uma janela de chat vai abrir do lado.
  3. É por ali que você vai conversar com os agentes do Mastermind.
  4. Para começar, digite o comando abaixo e pressione Enter:
digite: @workspace-chief
🎉Pronto! Você está dentro do Mastermind AIOX. Bem-vindo(a) ao time.
😊Não tem certo ou errado aqui — é só conversar como você faria por mensagem. Qualquer dúvida, fale com a Julia.

Salvar e atualizar

Duas rotinas simples que você vai repetir sempre.

💾

Como salvar seu trabalho

Sempre que terminar algo, salve para guardar na nuvem com segurança. No GitHub Desktop:

1Escreva uma descrição curta do que você fez.
2Clique em Commit to master.
3Clique em Push origin para enviar.
🔄

Como receber atualizações

Para trazer as novidades mais recentes para o seu computador. No GitHub Desktop:

1Clique em Fetch origin para verificar.
2Se aparecer, clique em Pull origin para baixar.
3Pronto — você está com a versão mais nova.
