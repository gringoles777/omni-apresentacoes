Aliança de Ouro
seus primeiros passos.

Nunca instalou nada disso? Este guia é para você. São 6 passos curtos, na ordem, e levam cerca de 30 minutos. Não precisa entender de tecnologia.

Faça um passo de cada vez. Cada passo diz exatamente o que clicar, baixar e colar. Travou? Tire um print da tela e mande para a Julia.

Comece por aqui

A configuração inicial

Esta configuração é feita uma vez. Depois dela, basta usar.

1

Ter sua conta no Claude

O Claude é a inteligência artificial que você vai usar na Aliança de Ouro. Para usar a versão que trabalha dentro do seu computador (o Claude Code), é preciso ter um plano pago.

› claude.ai Criar conta e assinar
  1. Acesse o site acima e crie sua conta com o seu e-mail.
  2. Dentro da conta, assine o plano Pro (ou o Max, se preferir).
Atenção O plano gratuito não dá acesso ao Claude Code. Se você já assina o Pro ou o Max, este passo está pronto. Guarde o e-mail e a senha: você vai usar no Passo 6.
2

Criar sua conta no GitHub

O GitHub é o lugar na internet onde fica guardado o seu material da Aliança. Pense nele como uma nuvem dos seus projetos. A conta é gratuita.

› github.com Clique em Sign up
  1. Acesse o site acima e clique em Sign up (cadastrar-se).
  2. Informe seu e-mail, crie uma senha e escolha um nome de usuário.
  3. Confirme o e-mail que o GitHub vai te enviar.
  4. Envie o seu nome de usuário para a Julia. É com ele que você recebe acesso ao seu material.
DicaAnote o nome de usuário e a senha em um lugar seguro.
3

Instalar o Git WindowsMac

O Git é o programa que baixa o seu material do GitHub para o computador e salva as suas alterações. Você instala uma vez e não precisa abrir.

No Windows:

› git-scm.com/downloads/win Download
  1. Acesse o link acima e clique em Click here to download.
  2. Abra o arquivo baixado e clique em Next em todas as telas, sem mudar nada, até Finish.

No Mac:

  1. Segure Command e aperte a barra de espaço. Digite Terminal e aperte Enter.
  2. Na janela que abrir, cole o comando abaixo e aperte Enter.
  3. Vai aparecer uma janelinha. Clique em Instalar e aguarde terminar.
só no Mac xcode-select --install
DicaNo Mac, se aparecer a mensagem de que já está instalado, ótimo: passo concluído.
4

Instalar o VS Code WindowsMac

O VS Code é o programa onde você vai trabalhar. É dentro dele que você abre a pasta do seu material e conversa com o Claude.

› code.visualstudio.com Download Windows / Mac
  1. Acesse o site acima e clique em Download for Windows, ou Mac, conforme o seu computador.
  2. No Windows: abra o arquivo baixado e clique em Next até o fim. No Mac: abra o arquivo baixado e arraste o VS Code para a pasta Aplicativos.
  3. Abra o VS Code. Na primeira vez, vai aparecer uma tela escrita "Welcome to VS Code".
Atenção Não clique no botão grande "Continue with GitHub". Esse login não é usado e ativa outra ferramenta que você não vai precisar. Clique no texto pequeno "Continue without Signing In", no canto inferior direito da janela.
5

Instalar o Claude Code WindowsMac

O Claude Code é o Claude trabalhando dentro do seu computador. Ele é instalado pelo terminal, uma faixa escura dentro do VS Code onde você cola um comando e aperta Enter. É só isso.

  1. Abra o VS Code.
  2. No menu lá em cima, clique em View (Exibir) e depois em Terminal. Vai abrir uma faixa escura na parte de baixo da tela: esse é o terminal.
  3. Copie o comando do seu computador (Windows ou Mac), cole dentro da faixa escura e aperte Enter.
Windows irm https://claude.ai/install.ps1 | iex
Mac curl -fsSL https://claude.ai/install.sh | bash
DicaAguarde terminar. Pode levar um ou dois minutos. Quando o terminal parar de escrever sozinho e o cursor voltar a piscar, terminou. Não achou o menu View? Use o atalho: segure Ctrl e aperte a tecla de crase, que fica acima do Tab.
WindowsO comando do Windows só funciona no terminal chamado PowerShell. Se der erro, ou se abrir uma janela falando em "WSL" ou "Subsistema do Windows para Linux" (pode fechar, você não precisa disso): ao lado do botão + do terminal tem uma setinha para baixo. Clique nela, escolha PowerShell e cole o comando de novo.
ObservaçãoSe aparecer um painel escrito "Chat" ou "Build with Agent" do lado direito, pode fechar no X. Não é o Claude Code.
6

Abrir o Claude e fazer login

Último passo: ligar o Claude Code à sua conta do Passo 1.

  1. Feche o VS Code por completo e abra de novo. Isso é necessário para ele reconhecer o que você acabou de instalar.
  2. Abra o terminal outra vez (View e depois Terminal).
  3. Digite a palavra abaixo e aperte Enter.
digite claude
  1. Ele vai fazer algumas perguntas em inglês (cor da tela, por exemplo). Pode apertar Enter para aceitar o padrão.
  2. Quando perguntar como entrar, escolha a opção da conta Claude com assinatura (Claude account with subscription). O navegador abre sozinho: entre com o e-mail do Passo 1 e clique em Authorize (autorizar).
  3. Volte para o VS Code. Se apareceu uma caixinha para você escrever, o Claude está pronto. Escreva oi e aperte Enter para testar.
Tudo bemSe o terminal responder que não reconhece a palavra "claude", feche o VS Code, abra de novo e repita. Se continuar, mande um print para a Julia.
Tudo pronto

Você concluiu a preparação

Se o Claude respondeu o seu "oi", sua máquina está pronta. O restante (baixar o seu material e começar a trabalhar) vamos fazer juntos no encontro.

Já tinha instalado o Node.js por uma versão antiga deste guia? Sem problema, pode deixar instalado.

J
