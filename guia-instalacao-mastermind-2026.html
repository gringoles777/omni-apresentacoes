Aliança de Ouro
seus primeiros passos.

Este guia prepara tudo o que você precisa para começar. São 8 passos, na ordem apresentada. Dentro do programa você vai aprender a usar a ferramenta AIOX.

O conteúdo é direto e em linguagem simples. Cada passo diz exatamente o que clicar, baixar e digitar.

Comece por aqui

A configuração inicial

Esta configuração é feita uma vez. Depois dela, basta usar.

1

Criar sua conta no GitHub

O GitHub é um serviço online que armazena seus projetos na nuvem e mantém o histórico de versões de cada arquivo.

› github.com Clique em Sign up
  1. Digite o endereço acima no seu navegador.
  2. Clique no botão Sign up (cadastrar-se).
  3. Informe seu e-mail, crie uma senha e escolha um nome de usuário.
  4. Confirme o e-mail que o GitHub vai te enviar. Pronto.
DicaAnote seu nome de usuário e senha em um lugar seguro. Eles serão usados nos passos seguintes.
2

Instalar o Git WindowsMac

O Git é o programa que baixa o projeto para o seu computador e salva as suas alterações. Ele funciona junto com o terminal.

› git-scm.com Download
  1. Acesse o site git-scm.com pelo link acima.
  2. Se você usa Windows, clique no botão escrito "Click here to download" para baixar.
  3. Se você usa Mac, siga os passos que aparecem na própria página para instalar.
  4. Depois de baixar (Windows), abra o arquivo e avance a instalação mantendo todas as opções no padrão até concluir.
DicaNão precisa entender cada tela do instalador. Mantenha o padrão e clique para avançar até o fim.
3

Instalar o Node.js WindowsMac

O Node.js é um programa base. Ele não é usado diretamente por você, mas é necessário para instalar o Claude Code no Passo 5.

› nodejs.org Download
  1. Acesse o site e clique no botão de baixar o Node.js. A versão recomendada já vem selecionada.
  2. Abra o arquivo baixado.
  3. Avance a instalação clicando em Next até chegar em Finish.
DicaMantenha as opções já marcadas por padrão. Elas são as corretas para este uso.
4

Instalar o VS Code WindowsMac

O VS Code é o programa onde você vai trabalhar. É dentro dele que você abre a pasta do projeto e usa o Claude Code pelo terminal.

› code.visualstudio.com Download Windows / Mac
  1. Acesse o site acima no seu navegador.
  2. Clique em Download for Windows, ou Mac, conforme o seu sistema.
  3. Abra o arquivo baixado e avance a instalação clicando em Next.
5

Instalar o Claude Code WindowsMac

O Claude Code é o assistente de inteligência artificial da Aliança de Ouro. Ele é instalado pelo terminal que já vem dentro do VS Code. O Node.js do Passo 3 é o que permite rodar o comando de instalação.

  1. Abra o VS Code.
  2. Abra o terminal integrado pelo menu Terminal, depois New Terminal. O atalho é Ctrl + crase.
  3. No terminal que abrir na parte de baixo, digite o comando abaixo e pressione Enter.
  4. Aguarde a instalação terminar. O terminal volta a aceitar comandos quando concluir.
digite npm install -g @anthropic-ai/claude-code
DicaDigite o comando exatamente como está, incluindo o sinal de arroba. Você pode copiar e colar para evitar erros. A crase fica na tecla acima do Tab, no canto superior esquerdo do teclado.
6

Baixar o seu repositório

Agora você vai baixar a sua pasta de trabalho da Aliança de Ouro para o seu computador, usando o mesmo terminal do VS Code.

  1. Ainda no terminal do VS Code, digite o comando abaixo, trocando SEU-NOME pelo seu nome.
  2. Pressione Enter.
  3. Na primeira vez, vai abrir uma janela pedindo para entrar na sua conta do GitHub. Faça o login.
  4. A cópia do projeto vai ser baixada para o seu computador.
digite git clone https://github.com/gringoles777/mastermind-SEU-NOME.git
DicaO nome exato do seu repositório é informado pela Julia. Em caso de dúvida sobre o nome, entre em contato com ela.
7

Abrir o projeto no VS Code

Agora você vai abrir no VS Code a pasta que baixou no Passo 6. É dentro dela que você vai trabalhar.

  1. No menu superior do VS Code, clique em File, depois Open Folder (Arquivo, Abrir Pasta).
  2. Selecione a pasta que acabou de ser baixada. O nome dela é mastermind-SEU-NOME.
  3. Clique em Abrir.
DicaO nome da pasta aparece na barra lateral esquerda do VS Code quando ela é aberta corretamente.
8

Começar a usar

Com a pasta do projeto aberta no VS Code, você vai abrir o terminal integrado de novo e iniciar o Claude Code.

  1. Abra o terminal integrado pelo menu Terminal, depois New Terminal.
  2. Digite claude e pressione Enter.
  3. Na primeira vez, vai pedir para fazer login na conta da Anthropic. Conclua o login.
  4. Depois de entrar, digite o comando abaixo e pressione Enter para começar a trabalhar:
primeiro claude
depois @workspace-chief
DicaApós o login inicial, o comando claude não pede login de novo.
No dia a dia

Salvar e atualizar

Duas rotinas simples que você vai repetir sempre.

Salvar

Como salvar seu trabalho

Quando terminar, peça ao próprio Claude Code para salvar. No terminal onde ele está aberto:

1Escreva algo como: salve e suba meu trabalho.
2Pressione Enter.
3Ele guarda as alterações e envia para o GitHub automaticamente.
Atualizar

Como receber atualizações

Para receber as novidades do material, é só pedir ao Claude Code. No terminal onde ele está aberto:

1Escreva: baixe as últimas atualizações do projeto.
2Pressione Enter.
3Ele cuida disso para você. Pronto, você está com a versão mais nova.
J

Dúvidas? Fale com a Julia.

Em caso de dúvida em qualquer passo deste guia, entre em contato com a Julia.

Ela acompanha o processo de configuração e uso da Aliança de Ouro.
