Resumo executivo

O workflow "My workflow 15" (ID YC49ifRugN1izCuN) está falhando de forma recorrente com o erro "The service is receiving too many requests from you" no nó Append or update row in sheet (Google Sheets).

O workflow utiliza dois Schedule Triggers paralelos que consultam dados no MySQL, iteram sobre os resultados em loop (splitInBatches) e tentam gravar cada item no Google Sheets sem nenhum intervalo entre as requisições. Isso viola o limite de taxa da API do Google Sheets, que aceita no máximo 100 requisições por 100 segundos por usuário.

O fix é direto: adicionar um nó Wait de 1–2 segundos imediatamente antes do nó Google Sheets dentro de cada loop. Não é necessário alterar a lógica de negócio.

Causa raiz

Rate limit da Google Sheets API sem throttle no loop

A Google Sheets API impõe um limite de 100 requisições por 100 segundos por usuário (1 req/seg em média). O workflow não respeita esse limite ao iterar sobre os registros do MySQL — cada iteração do loop dispara uma chamada à API imediatamente, sem aguardar.

Com volumes maiores de dados ou execuções simultâneas dos dois fluxos paralelos, o limite é ultrapassado e o Google rejeita as requisições com HTTP 429 (Too Many Requests), que o n8n mapeia como "The service is receiving too many requests from you".

Fix solicitado

Adicionar nó Wait antes do Google Sheets em cada loop

Inserir um nó Wait (tipo n8n-nodes-base.wait) imediatamente antes do nó Append or update row in sheet nos dois fluxos paralelos do workflow.
